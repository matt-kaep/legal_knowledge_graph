## 1. Setup — module `metrics.py` factorisé

Création de `05-Technique/benchmark/etape1_embedding_pur/scripts/metrics.py` regroupant les 5 fonctions atomiques du panel.

### 1.1 Conventions retenues (post-Week-9)

| Métrique | Convention |
|---|---|
| M1 = Recall@K | $|GT \cap R[:K]| / |GT|$, NaN si GT vide |
| M2 = rang moyen normalisé | custom, cap rang à $K{+}1$, denom $(b'+1)/2 - (K+1)$ avec $b' = \min(\|GT\|, K)$ |
| Hit@K | binaire $\{0, 1\}$ par question |
| MRR@K | $1/\text{rang(1$^{er}$ GT)}$ cappé à $K$, $0$ si aucun GT $\in$ top-$K$ |
| NDCG@K | rel **binaire** $\{0, 1\}$, DCG / IDCG avec $\log_2(i{+}1)$ |

**Discussions actées (cf. présentation Week-10 slides 9-10)** :
- MRR cappé à K (pas full ranking) → cohérent avec le reste du panel
- NDCG binaire pour l'instant ; multi-niveau (central/support/contextuel) viendra après enrichissement GT (chantier 3)
- Pas de MAP@K (corrélé fortement à NDCG sur rel binaire) ni de Precision@K (non interprétable avec $|GT|<K$)

### 1.2 Helpers de regroupement

- `all_metrics(ranked, gt, k, suffix="")` → dict 5-clés avec suffixe optionnel (`_strict`, `_ext`, ...)
- `panel_strict_ext(ranked, gt_strict, gt_ext, k)` → 10 colonnes (5 strict + 5 ext) pour côté articles
- Côté JP : `all_metrics` sans suffixe (5 cols)

### 1.3 Sanity check

Validation avec cas trivial sur 5 cas (singleton rang 1, singleton rang 3, hors top-K, |GT|=2 partiel, |GT|=3 top complet) — toutes les valeurs sont cohérentes avec les définitions. Notamment :
- Singleton rang 1 → 5 métriques à 1,0
- Singleton rang 3 → M1=1, Hit=1, MRR=0,333, NDCG=0,5, M2=0,6
- |GT|=2 partiel → MRR=1 (premier GT en 1) mais M1=0,5 (moitié manquée)

## 6. Anomalies / points à investiguer

- **MRR étendu PPR α=0,85** vaut 0,666 (très haut) alors que M1 étendu n'est que 0,421. Cohérent : MRR mesure le premier GT, qui est presque toujours dans le top-2 ; M1 mesure la couverture des 7 GT en moyenne. L'écart MRR-M1 est même un **signal positif** : le premier hit est précoce, mais on rate les hits suivants.
- **Sym-norm cohérent à 0,01 près de cosine sur 5 métriques** : il existe un petit écart résiduel (M1 strict 0,462 vs 0,459, +0,003) qui croît avec α — pas un collapse strict mathématique mais une stagnation. Hypothèse : la masse résiduelle qui reste sur le seed via le facteur (1-α) ne suit pas exactement la marche aléatoire. Pas critique mais à noter.
