# Objectifs & Perimetre

## Objectif principal

Concevoir et prototyper un **knowledge graph de la jurisprudence francaise** permettant a un agent IA de naviguer de maniere structuree dans le corpus juridique.

## Sous-objectifs

1. **Etat de l'art** : Cartographier les travaux existants (KG juridiques, ontologies, GraphRAG, agents)
2. **Modelisation** : Definir l'ontologie et le schema du KG (entites, relations, proprietes)
3. **Pipeline d'ingestion** : Concevoir la chaine d'extraction depuis les sources ouvertes (Judilibre, Legifrance)
4. **Agent** : Prototyper un agent capable de traverser le graph pour repondre a des questions juridiques

## Perimetre

### Inclus
- Jurisprudence francaise (Cass., CA, TJ)
- Articles de loi (codes)
- Principes juridiques
- Arguments / moyens de cassation
- Relations entre ces entites

### Hors perimetre (pour l'instant)
- Droit europeen (sauf connexions)
- Doctrine
- Contrats prives

## Criteres de succes

- [ ] Etat de l'art structure et complet
- [ ] Ontologie juridique francaise formalisee
- [ ] Prototype fonctionnel sur un sous-corpus
- [ ] Agent capable de repondre a des questions de navigation juridique
